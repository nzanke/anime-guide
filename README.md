# アニメ放送枠タイムテーブル

1960〜1990年代のテレビアニメを、曜日・時間帯・局ごとに半年単位の番組表で見るサイトです。

- ゴールデンタイム（19:00・19:30）：1960年代、1970年代、1980年代
- 朝・夕方（19時より前）：1980年代、1990年代後半

## 表の決まり

- 1年を「春＝4〜9月」「秋＝10〜翌3月」に分け、その半期に3か月以上放送された番組を入れています（3か月以上の番組がない半期は、1か月以上放送された番組から1本）。
- 局は系列でまとめています（読売テレビ→日本テレビ、朝日放送・名古屋テレビ→テレビ朝日、毎日放送→TBS、関西テレビ→フジテレビ、テレビ大阪ほか→テレビ東京）。
- 「（再）」は再放送、「帯」は月〜金（月〜土）に毎日放送された番組です。
